# chanx-kit brand

chanx-kit shares the chanx letters: the **c** holds a message to broadcast and the **x** is a hub
where channels meet. The dots are the messages, and their colour marks the project: sky for
chanx (Python), yellow for chanx-js, green for chanx-kit.

## Files

| File | Use |
|---|---|
| `chanx-kit-wordmark.svg` | Main logo on light backgrounds |
| `chanx-kit-wordmark-dark.svg` | Main logo on dark backgrounds and on the docs header |
| `cx-symbol.svg`, `cx-symbol-dark.svg` | Short form, where the full name does not fit |
| `cx-app-icon.svg`, `icon-512.png`, `apple-touch-icon.png`, `favicon.ico`, `favicon-32.png` | Square icon: avatars, app icons, browser tabs |
| `social-card.png` | Link previews (1280 × 640); also upload it as the GitHub social preview |
| `chanx-kit-wordmark-black.svg`, `chanx-kit-wordmark-white.svg` | One-colour versions |

## Colours

| Name | Hex | Where |
|---|---|---|
| Navy | `#1E3A8A` | Letters on light backgrounds, icon tile, docs header |
| Green | `#16A34A` | Dots on light backgrounds |
| Light green | `#22C55E` | Dots on dark backgrounds and on the icon tile |
| White | `#FFFFFF` | Letters on dark backgrounds and on the icon tile |

## Rules

- Keep empty space around the logo of at least half the height of the letter **c**.
- Below 100 px wide, use the `cx` symbol instead of the wordmark.
- Do not recolour parts independently, stretch, rotate, add effects, or retype the name in a
  font. The letters are drawn.
